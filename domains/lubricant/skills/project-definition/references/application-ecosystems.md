## 通用规则

1. **先判产品形态**：提问前先判定目标产品是油（oil）、脂（grease）、干膜还是其他固体润滑形态。谐波减速器等精密件以**脂**为主，不是所有应用域都是"润滑油"。
2. **对标 = 同应用域、同形态的玩家**：综合润滑油品牌（长城/昆仑/统一/美孚/壳牌等）只有在**该应用域确有专用产品线**时才可作为对标项。
3. **默认兜底 = 违规**：用户已指出"长城/昆仑/统一没有谐波减速器产品"——在其无产品线的应用域把它们列为"国产一线对标"属于事实错误，等同于编造基准产品。

## 应用域：谐波减速器（精密谐波齿轮减速器）

| 维度 | 内容 |
|---|---|
| 产品形态 | 润滑脂为主（全寿命免维护填充）；特殊高温/长寿命工况有脂替代油方案 |
| 随机配套标杆 | 哈默纳科（Harmonic Drive）原厂脂：SK-1A、SK-2 等型号，按温度/寿命/力矩要求分档 |
| 专业脂供应商 | 日本协同油脂（Kyodo Yushi）；出光（Idemitsu）DAPHNE 系列；THK（AFB 系列）；NOK 等精密机构脂厂商 |
| 关联域 | RV 减速器（纳博特斯克 Nabtesco 配套脂）、精密丝杠/导轨脂——同属精密传动脂生态，可参考但工况不同 |
| 国产格局 | 减速器主机厂（如绿的谐波等）随机配套脂以日系或定制为主；国产品牌专用谐波减速器脂尚不成体系，"国产对标"须用户指定具体产品，不得默认套用长城/昆仑/统一 |
| 关键性能维度 | 低温起动力矩、宽温域力矩稳定性、蒸发/扩散特性、与减速器等寿命、微振磨损（fretting）抑制、橡胶/塑料件相容性 |
| 工况要点 | 高减速比啮合、薄油膜、频繁启停/微幅摆动、伺服温升，-40~120℃ 级常见 |

*条目待办：SK 系列脂型号谱、各供应商具体牌号与性能参数 → 需 TDS 级调研补全。*
